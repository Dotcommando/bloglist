# Verification cases

- AC-1. Card shows the installed version and the correct source action. Reload with an older Completed ID shows no proposal.
- AC-2. File and repository proposals reuse the card confirmation. A foreign package cannot be applied from the card. Interrupted apply can be reconciled after reload.
- AC-3. Exact matching repository asset records the selected add-on source without activation. Mismatched key and digest do not reserve a record; existing permission and transport limits remain. Verify the application unit and actual HTTP/database composition.
- AC-4. Versions and build metadata agree. Verify the local site from its recovered archive with no add-on update applied during delivery.
