# Behavior

System Admin manages installation-wide add-on updates on each installed card. The card shows the active version, site enablement and connected GitHub source. It offers a file update and either a repository check or a source-link form. The same card reviews the exact proposed versions, mode and global scope before apply. A completed historical operation never appears as an actionable candidate. Pending work and uncertain outcomes can be reconciled after reload.

Connecting a source accepts the exact already active package and records its repository identity. Wrong keys or mismatched package bytes leave the source and runtime unchanged. Fresh installation remains available separately. A workflow that associates a different or newer artifact with a previously unrelated source is outside this change.
