# Design and cases

Extend the admin page summary with optional role metadata. The CMS supplies
the field for every delivered page. Events applies the creation-only filter
at the shared editor host. Existing selected IDs and page labels remain readable.
The data stays in the existing authorized browser workspace. No new request,
mutations, authority, persistence, or API asset location is introduced.

Verify host output for each system role and a regular page. Open both creation
forms on the local site and confirm the default and available choices are regular
pages. No form submission is needed.
