# Design

Extend the shared measured truncation component with the protected suffix
from the filename. Keep the current full accessible text and title. The media
browser measures within the card width and the shared file label style covers
file and folder results and the folder drawer. Presentation does not change
stored filenames, authorization or archive contents.

If a mandatory fragment is wider than the available line, the label clips
at the card boundary. The full accessible name and tooltip still identify it.
