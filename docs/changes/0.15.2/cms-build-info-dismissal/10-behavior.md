# Behavior

An administrator opens CMS version details from the header. Clicking outside or
pressing Escape dismisses it; another click/keyboard activation can reopen it.
Clicks inside keep the metadata readable/selectable. Escape restores trigger
focus; dismissal must not navigate, save data or change session/site/language.
Preserve displayed version, commit/checksum or existing local-build explanation.
Apply the core fix to the current local site without changing its content.
