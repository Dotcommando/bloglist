# Какие элементы админки показывать при смешанных разрешениях

Поставьте `V` в первом столбце напротив каждого элемента, который нужно показывать при указанном наборе прав. Каждый Action в каталоге по-прежнему выдаётся целиком.

Согласованные сценарии фиксируются в [журнале решений](interface-access-resolutions.md).

| V | Где | Права и граничный случай | Какой элемент можно показывать | Текущее поведение |
|--| --- | --- | --- | --- |
|  | Страницы | `cms.pages.create` без `cms.urls.materialize`. Создание черновика затрагивает домены Pages и URLs. | «Страницы» → «+» для обычного черновика | Показывается по `cms.pages.create`. |
|  | URLs | Только `cms.pages.create`, где второй домен URLs. | Сам пункт «URLs» | Требует отдельного Action раздела URLs. |
|  | Страницы | Есть `cms.pages.list`, отсутствует `cms.pages.read`. | Открытие редактора нажатием на запись дерева | Требует `cms.pages.read`. Сам список доступен. |
|  | Страницы | Есть `cms.pages.set-position` без `cms.pages.list`. | Перетаскивание и форма выбора родителя | Требуют списка для выбора объектов. |
|  | Страницы | Есть `cms.pages.update`, но нет `cms.publication.page-options`. | Просмотр опубликованной версии, выбор шаблона и URL, состояние публикации и настройки кеша | Черновик редактируется отдельно. Сведения публикации требуют её Action. |
|  | Страницы | Выдан `cms.publication.publish-page`, но нет `cms.pages.create` или `cms.pages.update`. | «Сохранить и опубликовать» | Кнопка требует оба применимых действия, поскольку сохраняет черновик и публикует его. |
|  | Страницы | У пользователя есть «Свои» или «Группы» для страниц и «Все» для `cms.publication.site-options` или `cms.urls.list`. | Названия, URL и статус страниц в панелях публикации и дерева URLs | Состав данных отдельного эндпойнта определяется его собственным правом на весь сайт. |
|  | Страницы | `cms.template-variables.list` и `cms.template-variables.read-page` без `cms.template-variables.save-page`. | Просмотр TV-полей страницы и отдельное редактирование значений | Чтение отдельно от сохранения значений. |
|  | Страницы и Шаблоны | `cms.json-ld.list` без `cms.json-ld.save`. | Связанные профили и переход в их редактор | Список зависит от права чтения JSON-LD. |
|  | Страницы и Файлы | Страницу можно изменить, но нет `cms.files.list`. | Файловый селектор Open Graph и миниатюры библиотеки | Селектор скрыт. |
|  | Страницы | Доступен только Markdown или JSON-LD preview Action страницы. | Отдельный раздел или открытие превью по прямой ссылке | Действие используется из редактора, когда можно открыть страницу. |
|  | Шаблоны, Чанки и Сниппеты | Разрешена запись исходника, отсутствует `cms.publication.publish-site`. | «Сохранить и применить» рядом с «Сохранить черновик» | Доступно сохранение исходника. Применение всего сайта требует отдельного права. |
|  | Шаблоны, Чанки и Сниппеты | Разрешён Action генерации превью, но нет доступа к чтению результата или страницам. | Выбор страницы, кнопка предпросмотра и iframe | Требуются права на генерацию и чтение превью. |
|  | Шаблоны, Чанки и Сниппеты | Список использований ссылается на страницы или исходники другого раздела. | Активные переходы к использующим объектам | Доступ к редактору определяется правом чтения целевого объекта. |
|  | Файлы | `cms.files.upload` / `cms.files.create-folder` без `cms.files.list`. | Загрузка в корень и создание папки без дерева и текущей версии библиотеки | Раздел открывается. Операции, которым нужна версия библиотеки, требуют списка. |
|  | Файлы | Выданы `cms.files.move` или `cms.files.delete`, отсутствует `cms.files.usages`. | Перетаскивание, поля переименования и перемещения, удаление с проверкой ссылок | Интерфейс проверяет использования перед операцией, поэтому нужны оба права. |
|  | Файлы и Страницы | `cms.files.move` может обновлять ссылки в страницах и публикации. | Кнопка подтверждения «Обновить ссылки» и переходы к найденным использующим объектам | Action перемещения выдаётся целиком. Переходы зависят от чтения целевого раздела. |
|  | Файлы | Есть `cms.files.list` без `cms.files.read-content`. | Миниатюра из приватной библиотеки, скачивание оригинала, открытие производных | Приватные ссылки требуют чтения содержимого. |
|  | URLs | Есть право изменения маршрута, но нет `cms.urls.list` либо `cms.urls.suggest`. | Дерево, форма адреса, поиск родителя или цели редиректа | Дерево требует списка, интерактивный поисковый селектор требует подсказок. |
|  | URLs | Есть `cms.urls.list` без `cms.pages.read`. | Сведения о связанной странице и ссылка в её редактор | Сведения приходят из каталога URLs. Для ссылки нужно чтение страницы. |
|  | URLs | Есть права на изменение маршрутов без `cms.urls.publish`. | «Применить маршруты» | Кнопка требует отдельного Action публикации маршрутизации. |
|  | Настройки | Доступно чтение основных настроек без `cms.site-settings.update` или `cms.publication.publish-site`. | Сохранение настроек и «Пересобрать сайт» | Каждое действие требует соответствующего права. |
|  | Hooks | Доступно создание обработчика без права подписки `cms.hooks.save-subscription`. | «Создать и назначить» и «Назначить» | Для комбинированного действия нужны оба права. |
|  | Аддоны | Пакет добавляет Actions с несколькими доменами, но его пункт меню или вложенные элементы пока не имеют явной привязки. | Название аддона, вложенное меню и кнопки внутри view | Требуется решение для каждого интерфейса аддона. |
