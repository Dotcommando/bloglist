# Release acceptance

Exercise the built administration UI under actual SystemAdmin, SiteAdmin and
Manager sessions. Verify individual publication and routing, conflicting edits
to role policies, add-on view and menu count grants, updates and installation
restore. Check protected endpoints at real HTTP admission and the transaction
boundary. The tests characterize the current contracts in
[administrative authorization](../../../arch/admin-authorization.md),
[site add-ons](../../../arch/site-addons-contracts.md) and
[live updates](../../../arch/live-addon-updates.md).

Earlier [editor and recovery journeys](../admin-site-journeys/80-remaining-scenarios.md)
remain in the release gate. Extend existing role, archive and add-on evidence
where its fixtures already own the required resources.
