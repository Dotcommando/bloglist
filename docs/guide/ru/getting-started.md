# Начало работы

[Руководство](README.md) · [Модель](concepts.md) · [Справочник](reference.md)

В редактируемом сниппете cms доступен как локальная переменная и как context.cms.
Импортировать модули в тело сниппета нельзя. Пример сниппета без параметров
с обязательным результатом типа String:

```typescript
const page = await cms.pages.getDraft({ pageId: context.pageId });
return page?.title ?? '';
```

Назовите сниппет DraftTitle и подключите в шаблоне или чанке:

```html
[[DraftTitle? &as=`title`]]
<h1>[[+title]]</h1>
```

Для фазы Request используйте [[!DraftTitle? &as=`title`]]. Если документ зависит
от Request-значений, укажите доставку Request. Плейсхолдер экранируется.
Опубликуйте страницу и активируйте релиз обычной операцией публикации.
Сохранение черновика само по себе документ не публикует.

Для публичных данных другой страницы обычно подходит getPublished.
getDraft намеренно читает редактируемый контент; его вывод в публичную разметку —
явное раскрытие данных автором доверенного кода. При первой публикации
getPublished может вернуть null: активного релиза ещё нет.

Нативный зарегистрированный сниппет получает тот же клиент в context.cms.
Его регистрация, контракты параметров/результата и поддерживаемые фазы явные.

Пакетный аддон получает host.cms, привязанный к своему addonKey:

```typescript
const cms = await host.cms.forSite(trustedSiteId);
const page = await cms.pages.getDraft({ pageId });
await cms.pages.update({ pageId, title: 'Новый заголовок' });
```

trustedSiteId берите из проверенного хостом сопоставления сайта или
аутентифицированного административного контекста, а не напрямую из запроса.
Хост проверяет подключение аддона при каждом вызове, даже если клиент уже получен.
По умолчанию требуется Enabled. Для обслуживания сохранённых подключений
можно явно выбрать AdministrationRetained.

Используйте фиксированные версии пакетов и контрольные суммы lockfile.
Синтетический аддон находится в отдельном проекте и предназначен только для
изолированных тестовых сред. В CMS он не установлен и не зарегистрирован.
