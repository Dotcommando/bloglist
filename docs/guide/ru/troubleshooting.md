# Диагностика

[Руководство](README.md) · [Справочник API](reference.md)

| Симптом | Причина и действие |
| --- | --- |
| Request-сниппет не запускается или выдаёт старые данные | Кеш всей страницы может пропускать его выполнение для отдельного запроса. Проверьте политику CMS/CDN, отключите кеш страницы и опубликуйте нужное изменение; одного HTTP no-store недостаточно. Автоматическая проверка отсутствия Request-сниппетов пока не реализована. |
| /api/cms даёт 404/405 | cms — приватный серверный клиент. Используйте сниппет или host аддона, а не новый REST-маршрут. |
| Validation для siteId/actorId/signal | Уберите служебные поля из аргументов. kind задаёт клиент только в templates/chunks/snippets; в остальных группах действуют бизнес-контракты. |
| Неизвестный фильтр/сортировка | Используйте разрешённые поля и asc/desc. Операторы MongoDB и произвольные пути не поддерживаются. |
| null в пагинации отклонён | Для значения по умолчанию не передавайте параметр. null отличается от отсутствия. |
| getDraft отклоняет чужую страницу | Сохраняется изоляция сайта. Не подставляйте данные другого сайта. |
| getPublished возвращает null | Проверьте страницу, выбранный релиз, наличие маршрута и сохранённую версию. До первой публикации активного релиза может не быть. |
| Новый черновик не виден публично | Нужна явная публикация. Изменения Build-данных и состава списков требуют пересборки. |
| Preview изменил данные | Команды в preview разрешены принятой политикой. Проверяйте результат операции; рендерер не делает откат. |
| Conflict/StaleWrite | Перечитайте объект и его версии. Не перезаписывайте изменения другого редактора. |
| AddonDisabled/AddonUnavailable | Проверьте подключение сайта, фиксированный пакет, совместимость SDK и миграции аддона. Старый клиент проверяется повторно. |
| Ошибка обязательного сниппета | Проверьте типы параметров/результата, фазу, бизнес-ошибки и ограничения worker. Технические детали worker публично не раскрываются. |
| API файлов недоступен | Явно настройте файловое хранилище. Неявного или фиктивного хранилища нет. |
| Файлы не помещаются в worker | Массивы байтов увеличивают закодированные данные. Память и результат worker ограничены независимо от limit списка. |
| Неопределённый исход команды | Проверьте бизнес-идентичность/версию и контракт идемпотентности. Тайм-аут worker не отменяет уже выполняющуюся запись БД. |
| Дорогой offset/сортировка title | Результаты материализуются и обрабатываются в памяти. См. реальные индексы и пути чтения; измерения производительности не заявляются. |

SDK 0.4.0 содержит переносимые контракты данных. Runtime-пакеты закрепляют
совместимость SDK точно; перед обновлением установки пересоберите пакеты под
выбранную версию. Для проверки аддона не импортируйте исходники соседнего проекта
и не заполняйте бизнес-регистры чистой CMS.
