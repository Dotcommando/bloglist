# Диагностика

[Установка](INSTALLATION.md) · [English](../en/troubleshooting.md)

Начните с `docker compose ps`, `docker compose logs --tail 100 app`,
`docker compose logs --tail 100 proxy` и `docker compose logs --tail 100 cloudflare`.
Не публикуйте приватные переменные окружения и сырые ошибки базы/провайдера.
Команда просмотра сохранённого состояния находится в [главе Cloudflare](cloudflare.md).

| Симптом | Что проверить |
| --- | --- |
| Ошибка аутентификации/авторизации | Токен и аккаунт, срок действия, права Worker/доменов и исходящий IP; проверяйте с хоста исполнителя |
| Backend | DNS, порт 443, сертификат Caddy и ответ HEAD на backend `/admin/` |
| Конфликт домена | Другой Worker или обычная DNS-запись публичного hostname; не удаляйте чужие записи |
| Storage | Mount-пути исходников, публикаций и медиа, права, активную публикацию и целостность файлов |
| Нет публикации | Опубликуйте сайт; сохранения черновика недостаточно |
| OutcomeUnknown | Завершите/согласуйте старую загрузку до повтора; сохраните историю провайдера |
| CMS не запускается после обновления | Примените и проверьте новую миграцию новым образом; сохраните старые отметки |
| Отклонён origin входа | Откройте канонический административный адрес; проверьте Host и отсутствие петли прокси |

После переноса/деплоя проверьте публичные документы, медиа, CSS, живой API и админку.
Ответы API/admin/Request не должны кешироваться. Локально подготовленные файлы или
один exit code не доказывают успешный внешний деплой. Храните резервные копии
приватно и различайте восстановление данных и откат деплоя провайдера.
