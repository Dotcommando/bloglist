# Bloglist

Minimal NestJS starter. `GET /` returns `Hello World!`.

Requires Node.js 26.7.0 and npm 11.19.0.

```sh
npm ci
npm run start:dev
```

The application listens on port 3000 by default. Set `PORT` to override it.

```sh
npm run format
npm run lint
npm run typecheck
npm run build
npm test
npm run test:e2e
```

After building, run `npm run start:prod`.
